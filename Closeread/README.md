Title: Hurricane Closeread

Description:
This document is a closeread document visualizing the formation of hurricanes. The specific example is about Hurricane Katrina in 2005, however the hurricane ID can be changed to visualize any hurricane.

Details:
- Uses the ibtracs dataset to visualize hurricane paths.

Inputs:
- ibtracs dataset (CSV file): Contains hurricane details including ID, 
  year, wind speed, latitude, and longitude.
- User-selected filters:
  - Hurricane ID

Output:
- Closead of specific hurricane path

![](Closeread_hurricane.gif)

Note: ensure closeread extension exists to be able to render the closeread file. If this is not the case run this command in the terminal:

```bash
quarto add qmd-lab/closeread
```
